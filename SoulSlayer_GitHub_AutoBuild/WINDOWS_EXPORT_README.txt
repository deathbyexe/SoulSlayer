Soul Slayer - Windows export (Godot 4)

1. Import project.godot into Godot 4.
2. Open Editor > Manage Export Templates and install matching version templates.
3. Open Project > Export, select Windows Desktop.
4. Choose export destination build/SoulSlayer.exe and click Export Project.
5. Keep SoulSlayer.exe and SoulSlayer.pck in the same folder if Godot exports both.
6. Before testing, back up your existing save data.

Note: This archive contains the project configured for export, not a compiled EXE.
