Soul Slayer 1.0 — Первый релиз
================================
Новая заставка / главное меню: Играть, режим экрана, Сохранить и выйти.
ESC возвращает в главное меню с сохранением.
F11 переключает полноэкранный режим.
Старый путь сохранения user://soul_slayer_save.json не менялся.
Все механики предыдущей версии сохранены.

Для сборки: поместите содержимое архива в КОРЕНЬ вашего GitHub репозитория
SoulSlayer, замените старые файлы, сделайте Commit и Push.
GitHub Actions автоматически создаст SoulSlayer-Windows-x64.

ВАЖНО: этот исходный проект не проверялся запуском в Godot.
После сборки EXE проверьте старт, меню, ESC, загрузку сохранения,
навыки, оружие и перерождение. Сделайте резервную копию сохранения.
